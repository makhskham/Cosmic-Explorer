# 🚀 Cosmic Explorer  

![Demo GIF](assets/spacegif1.gif) 

## 🌌 About  
A first-person 3D space exploration game where players:  
- Navigate a realistic solar system with orbital physics  
- Discover a morphing black hole with interactive warp effects  
- Transition to a 2D cartoon farm dimension  
- Built with **Java3D** (solar system) and **LWJGL** (farm world)

## 🔧 Technologies  
- **Core**: Java 8, Java3D, LWJGL  
- **Design**: Blender (3D models), Photoshop (textures)  
- **Audio**: JOAL  
- **Project Management**: Scrum (Trello/GitHub Projects)
